# 机器人 DIY 论坛功能清单

## 1. 文档说明

本文档基于当前 [database-design.md](D:/JavaProjects/robot-diy-forum/docs/database-design.md) 的数据库设计整理，目标是明确：

- 当前论坛初版需要实现哪些功能模块
- 每个模块需要做到哪些具体功能
- 每个功能和哪些表有关
- 哪些属于前台用户功能
- 哪些属于后台管理员功能

当前版本以“论坛初版可上线”为目标，已经包含附件上传能力，但暂不包含私信、点赞、收藏、举报、积分、消息通知等扩展能力。

---

## 2. 功能范围总览

当前初版建议实现以下核心模块：

1. 用户与认证模块
2. 分类模块
3. 主题帖模块
4. 回复模块
5. 标签模块
6. 附件模块

8. 后台管理模块
9. 通用基础能力模块

## 3. 用户与认证模块

对应表：

- `sys_user`

### 3.1 用户注册

需要实现的功能：

- 用户通过 `username + email + password` 注册
- 校验用户名不能为空
- 校验用户名长度是否合法
- 校验邮箱不能为空
- 校验邮箱格式是否合法
- 校验密码不能为空
- 校验密码长度是否合法
- 校验用户名是否已存在
- 校验邮箱是否已存在
- 密码必须加密后再入库
- 新注册用户默认角色为 `USER`
- 新注册用户默认状态为 `1`

### 3.2 用户登录

需要实现的功能：

- 用户通过用户名和密码登录
- 校验用户是否存在
- 校验密码是否正确
- 校验用户状态是否为启用
- 登录成功后生成登录态
- 支持后续接口识别当前登录用户

建议登录态方式：

- `JWT Token`

### 3.3 用户退出登录

需要实现的功能：

- 前端清除 token
- 后端可提供退出接口

### 3.4 获取当前登录用户信息

需要实现的功能：

- 获取当前登录用户基础信息
- 返回字段至少包括：
  - 用户ID
  - 用户名
  - 邮箱
  - 角色
  - 状态
  - 头像

### 3.5 用户资料修改

初版建议实现：

- 修改头像

可选扩展：

- 修改密码
- 修改邮箱

### 3.6 用户状态管理

管理员需要实现的功能：

- 启用用户
- 禁用用户
- 被禁用用户不能登录
- 被禁用用户不能发帖
- 被禁用用户不能回复
- 被禁用用户不能上传附件

## 4. 分类模块

对应表：

- `forum_category`

### 4.1 分类树查询

前台需要实现的功能：

- 查询所有启用的分类
- 支持父分类和子分类结构返回
- 只展示未删除分类

### 4.2 分类详情展示

需要实现的功能：

- 查看分类基本信息
- 返回分类名称
- 返回分类描述
- 返回父分类信息
- 返回分类状态

### 4.3 分类下帖子列表

需要实现的功能：

- 查询某分类下的主题帖
- 支持分页
- 只查询未删除帖子
- 分类本身必须处于启用状态

### 4.4 后台分类管理

管理员需要实现的功能：

- 新增分类
- 编辑分类
- 删除分类
- 启用分类
- 停用分类
- 设置父分类

校验规则：

- 分类名称不能为空
- 同一父分类下名称不能重复
- 父分类不能形成循环引用
- 有子分类或有帖子时不允许直接删除

---

## 5. 主题帖模块

对应表：

- `forum_topic`

### 5.1 发布主题帖

需要实现的功能：

- 登录用户可以发布主题帖
- 必须选择分类
- 必须填写标题
- 必须填写正文
- 正文支持 Markdown
- 支持给主题帖绑定标签
- 支持给主题帖上传附件
- 系统自动记录发帖人 `creator_id`
- 新帖子默认状态为 `1`

校验规则：

- 用户必须登录
- 用户必须启用
- 分类必须存在
- 分类必须启用
- 分类必须未删除
- 标题不能为空
- 正文不能为空

### 5.2 主题帖列表

需要实现的功能：

- 首页帖子列表
- 某分类下帖子列表
- 支持分页
- 支持按创建时间倒序展示
- 只展示状态正常且未删除的帖子

### 5.3 主题帖详情

需要实现的功能：

- 查看主题帖详情
- 显示标题
- 显示 Markdown 渲染后的正文
- 显示作者信息
- 显示分类
- 显示标签
- 显示附件列表
- 显示浏览量
- 显示回复数

建议实现：

- 详情页打开时浏览量自增

### 5.4 编辑主题帖

需要实现的功能：

- 用户可编辑自己发布的帖子
- 管理员可编辑任意帖子

可编辑内容：

- 标题
- 正文
- 分类
- 标签
- 附件

### 5.5 删除主题帖

需要实现的功能：

- 用户可删除自己的帖子
- 管理员可删除任意帖子
- 删除采用逻辑删除

建议同步处理：

- 逻辑删除该帖子下回复
- 逻辑删除该帖子下附件

### 5.6 主题帖状态管理

管理员需要实现的功能：

- 正常
- 隐藏
- 关闭

状态含义：

- `1`：正常
- `0`：隐藏
- `2`：关闭

业务规则：

- 普通用户只能看到 `status = 1` 的帖子
- `status = 2` 时不允许继续回复

## 6. 回复模块

对应表：

- `forum_reply`

### 6.1 发表顶层回复

需要实现的功能：

- 登录用户可以对主题帖发表评论
- 顶层评论的 `parent_reply_id = 0`
- 支持 Markdown 正文
- 支持回复附件上传

需要校验：

- 用户必须登录
- 用户必须启用
- 主题帖必须存在
- 主题帖未删除
- 主题帖不能是关闭状态
- 回复内容不能为空

### 6.2 回复某条评论

需要实现的功能：

- 登录用户可以回复某条已有评论
- 回复时传入被回复评论 ID
- 保存 `parent_reply_id`
- 保存 `reply_to_user_id`
- 支持附件上传

需要校验：

- 被回复评论必须存在
- 被回复评论必须属于当前主题帖
- 被回复评论未删除

### 6.3 评论列表查询

需要实现的功能：

- 查询某主题帖下的评论
- 支持分页
- 前端根据 `parent_reply_id` 组织楼中楼结构
- 评论中展示附件列表

建议返回字段：

- 评论 ID
- 回复人 ID
- 回复人用户名
- 回复人头像
- 父评论 ID
- 被回复用户 ID
- 内容
- 附件列表
- 创建时间

### 6.4 删除评论

需要实现的功能：

- 用户可删除自己的评论
- 管理员可删除任意评论
- 删除采用逻辑删除

建议同步处理：

- 逻辑删除该评论下附件
- 同步减少主题帖 `reply_count`

### 6.5 回复数维护

需要实现的功能：

- 新增回复后 `reply_count + 1`
- 删除回复后 `reply_count - 1`

## 8. 附件模块

对应表：

- `forum_attachment`

### 8.1 上传附件

需要实现的功能：

- 支持上传图片
- 支持上传 Word
- 支持上传 PDF
- 支持上传普通文件
- 记录上传人
- 记录附件归属类型
- 记录附件归属业务 ID

校验规则：

- 用户必须登录
- 用户必须启用
- 文件大小不能超过限制
- 文件类型必须在允许范围内

### 8.2 主题帖附件关联

需要实现的功能：

- 上传主题帖附件时，保存：
  - `related_type = TOPIC`
  - `related_id = 主题帖ID`

### 8.3 回复附件关联

需要实现的功能：

- 上传回复附件时，保存：
  - `related_type = REPLY`
  - `related_id = 回复ID`

### 8.4 附件列表查询

需要实现的功能：

- 查询某主题帖下的附件列表
- 查询某回复下的附件列表

### 8.5 附件删除

需要实现的功能：

- 用户可删除自己内容下的附件
- 管理员可删除任意附件
- 删除采用逻辑删除

## 11. 通用基础能力模块

### 11.1 登录拦截

需要实现的功能：

- 未登录用户访问受限接口时拦截
- 解析 token
- 获取当前登录用户

### 11.2 权限校验

需要实现的功能：

- 普通用户只能操作自己的帖子、评论和附件
- 管理员可以操作所有内容
- 只有管理员可以访问后台接口

### 11.3 参数校验

需要实现的功能：

- 注册参数校验
- 登录参数校验
- 发帖参数校验
- 评论参数校验
- 分类参数校验
- 标签参数校验
- 附件上传参数校验

### 11.4 分页能力

需要实现的功能：

- 帖子分页
- 评论分页
- 后台列表分页

### 11.5 统一返回结构

需要实现的功能：

- 接口统一成功/失败结构
- 统一错误码
- 统一错误信息

### 11.6 异常处理

需要实现的功能：

- 业务异常统一处理
- 参数异常统一处理
- 未登录异常统一处理
- 权限不足异常统一处理

### 11.7 时间字段维护

需要实现的功能：

- 自动写入 `create_time`
- 自动更新 `update_time`

### 11.8 逻辑删除支持

需要实现的功能：

- `forum_category`
- `forum_topic`
- `forum_reply`
- `forum_tag`
- `forum_attachment`

这些表删除时都采用逻辑删除

## 14. 当前版本不做的功能

以下功能当前不建议纳入初版：

- 私信
- 点赞
- 收藏
- 举报
- 全文搜索
- 消息通知
- 积分系统
- 徽章系统
- 操作日志

这些功能等论坛主流程跑通后，再决定是否扩展。
